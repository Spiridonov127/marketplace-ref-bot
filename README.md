# Marketplace Ref Bot

Автоматизированная система заработка на реферальных ссылках Яндекс Маркета: парсинг товаров, генерация статей и автопостинг в Дзен.

│                    GitHub Actions                        │

│  │ Parse (q6h)  │  │ Post (q4h)   │  │ Dashboard    │  │
│  └──────┬───────┘  └──────┬───────┘  └──────────────┘  │

│  └──────────────────────────────────┘                    │
│         │                 │                              │
│         ▼                 ▼                              │
│  ┌──────────────┐  ┌──────────────┐                     │

## Фичи

- **Парсер**: Яндекс Маркет
- **Автопостинг**: статьи в Дзен с товарами со скидками
- **Контент-генерация**: эмодзи, бейджи, CTA-кнопки
- **Трекинг кликов**: через inline-кнопки бота
- **Аналитика**: статистика по кликам, постам, маркетплейсам
- **Дашборд**: HTML-отчёт с Chart.js графиками
- **Дайджест**: ежедневный обзор лучших скидок
- **GitHub Actions**: бесплатная автоматизация 24/7

## Установка

### 1. Секреты GitHub

Добавьте в **Settings → Secrets and variables → Actions**:

| Секрет | Описание |
|--------|----------|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `ADMIN_USER_IDS` | ID админов через запятую |
| `YANDEX_DISTRIBUTION_PARTNER_ID` | Партнёрский ID Яндекс Дистрибуции (CPA) |
| `YANDEX_DISTRIBUTION_API_KEY` | API-ключ Яндекс Дистрибуции |
| `ORD_TOKEN` | Токен ОРД для маркировки рекламы |
| `DZEN_COOKIES_PATH` | Путь к cookies для публикации в Дзен |

### 2. Локальный запуск

```bash
cd marketplace-ref-bot
pip install -r requirements.txt
cp .env.example .env  # заполните переменные
python main.py
```

### 3. Запуск через GitHub Actions

Пуш в `main` активирует воркфлоу:
- **Parse**: каждые 6 часов
- **Post**: 4 раза в день (09:00, 13:00, 17:00, 21:00 МСК)

## Автоматизация (GitHub Actions — бесплатно)

- **3000 минут/мес** бесплатно на приватных репах
- Один запуск: ~30 секунд парсинг + ~10 секунд постинг
- ~10 запусков/день = ~300 мин/мес — в рамках бесплатного тира

## Как это зарабатывает

1. Парсер собирает товары со скидками с Яндекс Маркета
2. Генератор создаёт статью с CPA-ссылками (Яндекс Дистрибуция) и маркировкой ОРД
3. Бот автоматически публикует статью в Дзен
4. Читатели переходят по ссылкам и покупают
5. Вы получаете комиссию от партнёрской программы Яндекс Дистрибуции
6. Аналитика показывает, какие товары приносят больше всего кликов
